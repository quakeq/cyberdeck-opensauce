# cyberdeck-opensauce
repo for my cyberdeck project for hackclub opensauce

## features
- Storage
- Custom Battery with 10 hr lifespan
- Mechanical keyboard that's removable for access to wires and stuff.
- Watersealed Case
- 10.1 inch touchscreen
